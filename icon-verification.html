🔍 Manual Browser Testing

To test the app icon:

1. Visit https://voltrevo.github.io/uv-app/

2. iOS: Tap Share → Add to Home Screen

3. Android: Tap menu (⋮) → Install app or Add to Home Screen

4. Windows/Mac: Right-click → Create shortcut → Check "Open as window"

5. Verify icon displays correctly and matches sunscreen bottle design
